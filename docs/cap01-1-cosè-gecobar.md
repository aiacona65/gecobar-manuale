# 1. Cos'è GeCoBar™

GeCoBar™ è un'applicazione gestionale professionale sviluppata specificamente per la gestione completa di un esercizio commerciale — bar, tabaccheria, o attività mista. Copre in un unico programma tutte le aree operative e amministrative del locale: dalla cassa quotidiana alla contabilità, dal magazzino ai dipendenti, dalla documentazione alle statistiche. Non è un software generico adattato: è stato costruito attorno alle esigenze reali di questo tipo di attività.

L'applicazione gira su Windows, si connette a un database SQL Server che può essere installato in locale oppure ospitato su cloud Microsoft Azure, garantendo così la disponibilità dei dati anche da remoto e la protezione contro la perdita di informazioni in caso di guasto hardware.
